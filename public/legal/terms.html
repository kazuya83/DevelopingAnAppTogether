1. 本サービスについて

本サービスは、利用者が提案といいねで、このアプリそのものを一緒に育てていく場です。いいねが集まった提案は GitHub の公開 Issue になり、AI（Claude）が開発して、本サービスに反映されることがあります。提案が必ず開発される・思ったとおりに反映されるとは限りません。

アカウントを作ると、この規約とプライバシーポリシーに同意したものとします。

2. 禁止すること（不適切な投稿は一切認めません）

次のような提案・コメント・ユーザ名・アイコンは、投稿できません。見つけしだい削除し、アカウントを止めることがあります。

  • 法令に反するもの、犯罪につながるもの
  • 他人への攻撃・嫌がらせ・差別・脅し、なりすまし
  • 性的なもの、暴力的・残酷なもの
  • 自分や他人の個人情報（本名・住所・電話番号・メールアドレスなど）
  • 宣伝・スパム、同じ内容のくり返しの投稿
  • 本サービスや他のサービスへの攻撃、AI への指示の書き換えをねらったもの、本サービスやデータを消す・止めることを求めるもの
  • 他人の著作権・商標などの権利を侵すもの

3. 通報・ブロックと運営の対応

  • 不適切な投稿やユーザは、各画面のメニューから通報・ブロックできます。ブロックした人の投稿は表示されなくなります。
  • 運営は通報を確認し、24 時間以内に、投稿の削除やアカウントの停止など必要な対応をします。

4. 投稿の扱い

利用者は、投稿した提案・コメントを、本サービスの中での公開、GitHub の公開 Issue としての公開、本サービスの開発（AI に渡すことを含みます）に使うことを、運営に無償で許可するものとします。投稿の著作権は投稿者に残ります。

5. 免責

本サービスは、その時点の状態のまま提供します。AI による開発を含め、内容の正確さや、中断・変更・終了が起きないことは保証しません。運営に故意または重大な過失がある場合を除き、本サービスの利用で生じた損害について責任を負いません。
