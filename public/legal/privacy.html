プライバシーポリシー

みんなでアプリ開発（以下「本サービス」。iOS アプリとブラウザ版を含みます）／運営：みんなでアプリ開発 開発者／2026年11月26日 制定

1. 集める情報と使い道

  • ユーザ名・表示名・アイコン画像（アイコンは任意）：アカウントの識別と、提案・コメントの投稿者の表示に使います。
  • パスキーの公開鍵と、その付随情報：ログインに使います。顔や指紋などの生体情報は端末の中だけで使われ、本サービスには送られません。パスワードは扱いません。
  • 提案・コメント・いいね・ブロック・通報：本サービスの機能を提供するため、また不適切な投稿に対応するために使います。
  • 通知の宛先（デバイストークン）：iOS アプリで通知を許可した場合だけ、開発の進み具合やコメントを知らせるために使います。
  • ログインを保つための Cookie：ログインした状態を保つために使います。
  • アクセスの記録：不正な利用を防ぎ、障害を調べるために、サーバの提供元（Cloudflare）が記録します。

広告の表示、他社サービスをまたいだ追跡（トラッキング）、情報の販売は行いません。

2. 公開される情報

  • ユーザ名・表示名・アイコン・提案・コメント・いいねの数・活動の記録・貢献度は、ほかの利用者を含めて誰でも見られます。
  • いいねが基準の数に届いた提案は、タイトル・本文・提案者のユーザ名と表示名が、GitHub の公開リポジトリに Issue として載ります。

3. AI による開発

Issue になった提案のタイトルと本文は、本サービスを開発するために AI（Anthropic 社の Claude）に渡されます。AI に渡すのは提案の内容だけで、パスキー・Cookie・通知の宛先などは渡しません。

4. 情報を預ける先（外部サービス）

  • Cloudflare, Inc.：サーバとデータベース（データは日本国外のサーバに保存されることがあります）
  • GitHub, Inc.：Issue の公開
  • Anthropic, PBC：Issue になった提案をもとにした開発（AI）
  • Apple Inc.：iOS アプリへの通知（Apple Push Notification service）

法令にもとづく場合を除き、上のほかに個人の情報を第三者に渡すことはありません。

5. 削除

アプリの「ユーザ」→ 設定 →「アカウントを削除」から、いつでもアカウントを削除できます。削除すると、パスキー・いいね・コメント・通知の宛先・Issue になっていない提案が消えます。Issue になった提案は、本サービス上では投稿者とのつながりを消して残ります。すでに GitHub に公開された Issue の削除を希望する場合は、下の連絡先にご連絡ください。
