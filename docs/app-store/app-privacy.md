# App のプライバシー（App Store Connect「アプリのプライバシー」に答える）

- **プライバシーポリシー URL**：https://developing-an-app-together.minna-dev.workers.dev/legal/privacy
- 「データを収集していますか？」→ **はい**
- トラッキング（他社のアプリ・Web をまたいだ追跡、広告）→ **しない**（すべての種類で「トラッキングに使用：いいえ」）

| データの種類（Apple の分類） | このアプリで当たるもの | 目的 | ユーザにひも付く |
| --- | --- | --- | --- |
| ユーザコンテンツ → 写真またはビデオ | プロフィールのアイコン（任意） | App の機能 | はい |
| ユーザコンテンツ → その他のユーザコンテンツ | 提案・コメント・通報の理由 | App の機能 | はい |
| ID → ユーザ ID | ユーザ名・アカウントの ID | App の機能 | はい |

当たらないもの（「収集しない」）：
- 連絡先情報（名前・メール・電話）：集めない（表示名は自由なニックネーム。メールアドレスは聞かない）
- 位置情報・健康・金融・閲覧履歴・検索履歴・購入：集めない
- パスキー：生体情報は端末の外に出ず、サーバには公開鍵だけが届く（認証のための情報で、Apple の分類の収集に当たらない）
- 通知の宛先（デバイストークン）：通知を届けるためだけに使う
- 診断・使用状況：アプリとしては集めない（サーバの提供元 Cloudflare のアクセスの記録は、不正の防止と障害の調査のためだけ）
